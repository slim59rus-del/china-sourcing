# Поиск по Китаю — Android-приложение

Приложение ищет товар на **Taobao (淘宝)**, **1688 (阿里巴巴)** и **闲鱼 Idle Fish (Goofish)**,
само переводит запрос на китайский и показывает результаты ссылками на товар и на страницу
продавца с кратким описанием продавца по-русски.

---

## Что уже умеет

| Требование | Как сделано |
|---|---|
| Автоперевод запроса на китайский | `WebTranslator` (онлайн-переводчик, адрес меняется в настройках) с офлайн-подстраховкой `GlossaryTranslator` по словарю частых товарных слов |
| Отметить, где искать: одну, две или все площадки | Чипы источников на главном экране, множественный выбор: Taobao / 1688 / 闲鱼. Выбор сохраняется |
| Фильтр «количество продаж, от большего к меньшему» | Сортировка «По продажам»: карточки сортируются по счётчику продаж (Taobao `view_sales`, 1688 `sold`/`tradeNum`, 闲鱼 `想要`). Счётчики читаются вместе с множителем 万 (1.2万 = 12 000) |
| Фильтр «только фабрики/производители» | Двойной фильтр: серверный параметр для 1688 + разбор меток площадки на стороне приложения (工厂, 厂家, 源头, 生产, 实力商家, 超级工厂, OEM/ODM, 批发). Признаки перекупщика (旗舰店, 代购, 转卖, 二手) исключают товар из «фабричных» |
| Результат — ссылки на товар и/или на страницу продавца | В карточке видны ссылка на товар, ссылка на магазин продавца и кнопки «Товар» / «Продавец» (открывают браузер) и копирование ссылки |
| Краткое описание продавца на русском | `SellerSummarizer`: имя магазина, регион (переведён), срок работы, рейтинг, метки площадки и вывод «фабрика / похоже на посредника» — только из фактов карточки |
| Вход в аккаунт | Кнопка «Войти в аккаунт» открывает официальную страницу входа площадки во встроенном браузере; приложение сохраняет только полученную сессию |
| Красиво | Material 3, тёмная и светлая темы, фирменный градиент, карточки с бейджами площадок, статусы поиска по этапам |

### Экраны

1. **Поиск** — градиентная шапка с полем ввода, блок фильтров (площадки, сортировка, переключатель «только фабрики»),
   статус поиска, карточки результатов, предупреждения по площадкам, которые не отдали данные.
2. **Настройки** — статус входа по площадкам, адрес переводчика, адрес своего сервера подписи,
   число товаров с площадки, включение перевода названий, выход из аккаунтов.
3. **Вход** — встроенный браузер с официальной страницей входа площадки.

## Как получить готовый APK

Собрать установочный файл можно тремя способами. Проще всего первый — он не требует
устанавливать Android Studio.

### Способ 1. Автосборка в облаке GitHub (рекомендую)

В проекте уже лежит готовая сборка: `.github/workflows/build-apk.yml`.

1. Создайте на GitHub пустой репозиторий (можно приватный).
2. Загрузите туда **содержимое** папки `china-sourcing` (не саму папку) — через GitHub Desktop,
   веб-интерфейс или командой:
   ```
   cd china-sourcing
   git init
   git add .
   git commit -m "Поиск по Китаю"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git
   git push -u origin main
   ```
3. Откройте вкладку **Actions** репозитория. Сборка запустится сама; если нет — выберите
   «Сборка APK» → **Run workflow**.
4. Когда сборка закончится (примерно 3–5 минут), откройте её и скачайте внизу архив
   **ChinaSourcing-debug-apk** — внутри `app-debug.apk`.

Этот файл ставится на телефон как есть: скопируйте его на устройство, откройте и разрешите
установку из этого источника. Подпись у такой сборки отладочная — для личного использования
её достаточно, но в магазин приложений она не подойдёт.

Заодно эта сборка **проверит код**: если где-то опечатка или изменился API библиотеки,
в логе сборки будет видно точный файл и строку. Пришлите мне лог — поправлю.

### Способ 2. Android Studio

1. Android Studio → **Open** → папка `china-sourcing`.
2. Дождитесь синхронизации Gradle.
3. **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. Ссылка **locate** в появившемся сообщении откроет папку с `app-debug.apk`.

### Способ 3. Командная строка

В проекте есть `build-apk.sh` (macOS/Linux) и `build-apk.bat` (Windows). Нужны JDK 17 и Android SDK.

```
cd china-sourcing
./build-apk.sh
```

Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

**Про обёртку Gradle.** В архиве нет бинарного `gradle-wrapper.jar`, поэтому команды выше
вызывают установленный `gradle` напрямую — так сборка не зависит от обёртки. Если вы хотите
пользоваться `./gradlew`, создайте обёртку один раз:

```
gradle wrapper --gradle-version 8.7
```

## Первый запуск: аккаунты

Taobao, 1688 и 闲鱼 — площадки Alibaba Group. Поиск по ним обычным анонимным запросом они
не отдают: сервер требует сессию и одноразовый токен устройства. Поэтому:

1. Откройте **Настройки → Аккаунты площадок → Войти** для нужной площадки.
2. В открывшемся окне введите свой логин и пароль **на странице площадки**.
3. Нажмите «Готово». Приложение проверит сессию и покажет «вход выполнен».

Пароль приложению не передаётся и нигде не сохраняется — в зашифрованном хранилище лежит только
признак «вход выполнен», а сама сессия — это cookie, которые выдала площадка. Это и безопаснее,
и практичнее: у обеих площадок вход с нового устройства часто требует подтверждения по SMS,
а такой вход руками выполняется один раз и работает дальше.

Если какая-то площадка всё равно не отдаёт данные (у Alibaba сильная защита от автоматических
запросов), приложение не молчит: под карточкой предупреждения появятся кнопки
«Открыть поиск на сайте» — тот же запрос, уже переведённый, открывается на веб-странице площадки.

## Про свой сервер подписи (по желанию)

Запросы к площадкам подписываются токеном: `sign = md5(token & t & appKey & data)`.
Сначала приложение пробует подписать запрос само (так работает `MtopClient` —
он сам ведёт `_m_h5_tk`, подставляет время и повторяет запрос один раз, если токен устарел).
Если из вашей сети такой запрос не проходит, укажите в настройках адрес своего маленького
сервера: он принимает `api`, `v`, `host`, `data`, подписывает и возвращает JSON площадки.
Пример адреса, который приложение ожидает:

```
POST/GET  https://ваш-сервер/sign?api=...&v=1.0&host=...&data=...
```

Такой сервер удобно держать на VPS в Азии или за прокси — заодно решается вопрос с доступностью
площадок из вашей страны.

## Архитектура

```
app/src/main/java/com/leantech/finder/
├── MainActivity.kt              экран-переключатель (поиск / настройки / вход)
├── FinderApp.kt                 запуск контейнера зависимостей
├── data/
│   ├── net/                     MtopClient (подпись, cookie, повторы), Sign, CookieStore
│   ├── prefs/SettingsStore.kt   настройки и статусы входа в EncryptedSharedPreferences
│   ├── session/LoginManager.kt  вход, проверка живой сессии, выход
│   ├── source/                  TaobaoSource, Alibaba1688Source, XianyuSource, JsonCards
│   ├── translate/               WebTranslator, GlossaryTranslator, TranslatorChain
│   └── repository/              SearchRepository — весь проход поиска
├── domain/
│   ├── model/                   Marketplace, Product, Seller, SearchRequest, SortOption, SearchOutcome
│   └── seller/SellerSummarizer.kt  русское описание продавца
├── ui/                          Screen, AppViewModel, theme/, components/, screens/
└── di/ServiceLocator.kt
```

Разбор ответов площадок намеренно не привязан к одному пути в JSON: `JsonCards` рекурсивно
обходит ответ и собирает объекты, похожие на карточку товара, по набору известных полей
(`raw_title`, `view_price`, `view_sales`, `nid`, `nick`, `item_loc`, метки магазина и т. д.).
Имена контейнеров у площадок меняются — такой обход это переживает. Новое поле добавляется
в один список в начале `JsonCards`.

## Что стоит проверить на живом трафике

Код готов и логика целостна, но собрать и проверить его на устройстве можно только у вас:
в моей среде нет Android SDK и доступа к площадкам. Что нужно сверить один раз (правки — в одном-двух файлах):

1. **Имена API и полей.** В `TaobaoSource`, `Alibaba1688Source`, `XianyuSource` указаны
   `mtop.taobao.wsearch.appsearch`, `mtop.alibaba.pc.newsearch.searchoffers`,
   `mtop.taobao.idlemtopsearch.search`. Площадки их периодически переименовывают — проверьте
   актуальные по трафику веб-версии и замените константу.
2. **Параметры сортировки.** Значения отсортированы по смыслу площадки
   (`sale-desc`, `va_rmdarkgmv`, `asc/desc`); при необходимости подставьте те, что увидите в запросах браузера.
3. **Синтаксис строки фильтров 1688.** Сейчас отправляется `sellerType:factory`;
   фильтр «фабрика» продублирован на стороне приложения, поэтому результат не пострадает.
4. **Адрес переводчика.** Публичный переводчик может быть недоступен из вашей сети —
   укажите свой в настройках.

## Правовая заметка

Приложение использует ваш собственный аккаунт и ваш собственный вход. Оно обращается
к площадкам от вашего имени, с умеренной частотой (без массового парсинга). Учитывайте
правила площадок и не превращайте инструмент в массовый сбор данных.
